# reels-kit — монтаж вертикальных роликов для Reels / Shorts

Инструкция для ИИ-агента (Codex, Claude Code). Отвечать по-русски. Всё на ffmpeg + Whisper, главный инструмент —
`tools/edit.py` (формат `cuts.json` — в его шапке, пример — `examples/cuts-example.json`).

Python — только из окружения репо: `.venv/bin/python tools/edit.py …`. `./install.sh` ставит всё: это окружение,
FaceFusion в `~/tools/facefusion` и F5-TTS с Demucs в `~/tools/f5tts`. Если чего-то не хватает — запустить его ещё раз. Команды писать
полностью, без переменных-алиасов.

## Папки

Каждый ролик — своя папка в корне (`<ролик>/`), видео в git не попадают (см. `.gitignore`). Внутри:
`transcript.json`, `cuts.json`, `captions.ass`, результат `<ролик>_<сек>s.mp4`. Варианты — `cuts-<вариант>.json` →
`<ролик>-<вариант>_<сек>s.mp4`. Промежуточные рендеры без субтитров — в `<ролик>/work/`: наверху только готовое.
Расшифровки исходников — в `tx/<имя файла>.json` (по имени их ищет `mapwords`). Чужие скачанные ролики —
`<ролик>/origin/`. После рендера — сказать путь к файлу и открыть его: `open <файл>.mp4`.

## Команды

```bash
.venv/bin/python tools/edit.py transcribe <видео> transcript.json      # расшифровка + тайминги слов (локально)
.venv/bin/python tools/edit.py sheet <видео> sheet.jpg [шаг_сек]       # раскадровка — смотреть глазами
.venv/bin/python tools/edit.py words transcript.json <от> <до>         # слова с таймингами в диапазоне
.venv/bin/python tools/edit.py render cuts.json out.mp4                # нарезка + громкость −14 LUFS + HDR→SDR
.venv/bin/python tools/edit.py mapwords cuts.json transcript.json      # слова результата из tx/ без Whisper
.venv/bin/python tools/edit.py captions transcript.json cuts.json captions.ass [a|b|c|d|e|g|h]
.venv/bin/python tools/edit.py burn out.mp4 captions.ass final.mp4     # вшить субтитры
.venv/bin/python tools/edit.py frames out.jpg 6 a.mov:12.5 b.mov:3.0    # кадры в заданные секунды, сеткой
.venv/bin/python tools/edit.py onsets a.mov 45 48 [-32]                # отрезки речи — точные начала фраз
.venv/bin/python tools/edit.py envelope a.mov 45.4 46.6 [20]           # огибающая громкости по 20–40 мс
.venv/bin/python tools/edit.py facetrack a.mov 84 89.2 [0.3]           # точки лица для zoom.track (macOS Vision)
.venv/bin/python tools/edit.py denoise a.mov work/a-df.mov [14]        # ИИ-шумодав — копия с чистым звуком
.venv/bin/python tools/pitch.py a.mov 45 46.5                          # кто говорит: ребёнок / взрослый (F0)
.venv/bin/python tools/cards.py cards.json cards.ass                   # карточки-подписи, строка сверху, часы
.venv/bin/python tools/assmerge.py out.ass cap.ass cards.ass           # склеить субтитры и карточки
.venv/bin/python tools/sfxtag.py search sfx/ "whoosh transition" 5     # найти звук по описанию (CLAP)
.venv/bin/python tools/whip.py in.mp4 out.mp4 52 96 144 [--dir left|up|alt]   # свайп-переходы на склейках
.venv/bin/python tools/blurtrack.py check in.mp4 spec.json check.jpg   # где будет размытие — контуры на кадрах
.venv/bin/python tools/blurtrack.py render in.mp4 spec.json out.mp4   # размыть лишнее: пятно едет по ключевым точкам
~/.local/bin/yt-dlp -f 'bv*+ba/b' --merge-output-format mp4 -o "origin/reel.%(ext)s" <url>   # скачать рилс
```

Транскрипция по умолчанию локальная (mlx-whisper). Через OpenAI — третий аргумент `openai`, ключ
`OPENAI_API_KEY` в окружении или в `.env` в корне (`.env` в git не попадает). Ключ не печатать.

## Порядок работы

1. **Понять материал.** `sheet` каждого исходника и `transcribe`. Раскадровку смотреть обязательно.
2. **План нарезки — по расшифровке.** Каждая точка реза проверяется `words`: начало куска за 0.05–0.1 с до первого
   слова, конец через 0.05–0.1 с после последнего. Рез «на глаз» откусывает слова — главная ошибка.
3. **Проверить рез до субтитров.** После `render` — `transcribe` результата в `work/transcript-check.json` и прочитать
   целиком: обрезанные слова, повисшие хвосты, склеенные обрывки. `sheet` результата — глазами на стыки.
   В логе `render` должна быть строка `HDR → SDR: …` для клипов с айфона; на `sheet` небо синее, кожа тёплая.
4. **Субтитры.** `captions` печатает текст и число наложений (должно быть `0`). Ослышки Whisper — в `fix`,
   разорванные слова — в `merge`. Смотреть и список групп: склейки не по смыслу («Кого хотите мне без | разницы»)
   лечатся `breaks`, вспышки из одного слова — `joins`. Потом `burn`.
5. **Финальный `sheet`** — субтитр на каждом кадре на месте, ничего не наехало.
6. **Личное на экране.** Записи экрана и фон просмотреть: нет ли того, что не для публикации. Закрывать —
   `tools/blurtrack.py` (формат spec.json — в шапке файла): сперва `check` (контуры пятен на кадрах в ключевые моменты), потом
   `render`. Точки ставить через 0.2–0.3 с, где предмет двигается. Для лиц точки даёт `edit.py facetrack` (`"coords": "frac"`).
   Размывать готовый рендер до `burn` (субтитры останутся резкими) или окно исходника; HDR с айфона остаётся HDR.

До минуты из 3–4 минут исходника выходит за 10–15 итераций. Это нормально.

## Что резать

- Говорящая голова без картинки дольше 10–12 с в начале — смерть. Хук = проблема или завязка одной фразой.
- Выкидывать: приветствия, «ну и так далее», ожидание, рассуждения без картинки, извинения в конце.
- Длина: 60 с жёстко, 88–90 с свободнее. Короче — лучше.
- **Скетч с репликами:** обрывать на панчлайне, хвосты не нужны. Жёсткие стыки без переходов — правильно для жанра.
- **Порядок реплик в диалоге не менять** ради хука — лучше сжать паузы или начать позже.
- **Жанровые кадры:** зритель ждёт опознавательных кадров (поезд — перрон, окно, стук колёс; море — прибой).
  Если их нет — подложка звуком (`bed`) и строка-контекст сверху (`cards.py`, стиль `top`).
- **Чужой монолог поверх своего видео:** звук сплошняком, видео режется под реплики; глагол в тексте совпадает
  с действием в кадре («бьёт» — на кадре с ударом).
- **Подача, которую смешно слушать:** хук короткой фразой → пауза → наблюдение → одна история с эскалацией →
  реакция → панч. Паузы между блоками 0.4–0.6 с. Одиннадцать наблюдений подряд без пауз — монотонно.
  Панчлайн — крупный план и пауза после (у куска `end` видео дальше, чем `end` звука — добьётся тишиной).
- Обложку в Instagram выбирать вручную (кадр с реакцией).

## Скорость и звук

- Речь 1.1–1.4× — незаметно; паузы, ожидание — до 2.0×. Высота голоса сохраняется.
- Громкость всегда через `render`: каждый кусок к −18 LUFS, потом весь ролик к −14 (уровень Instagram/YouTube).
  Запись с телефона обычно −30…−35 — без нормализации в ленте почти не слышно. `"gain"` у куска — вручную.
- На стыках короткие фейды 40/60 мс. Если соседние куски берут `audio` из одного файла подряд (`end` = `start`),
  фейдов нет — звук идёт сплошняком, видео можно резать как угодно. Тогда `"match_loudness": false`.
- **Тихая домашняя запись:** `denoise` исходника (предел 14 дБ — иначе глотает тихие слова) → куски из
  `work/<имя>-df.mov` → `"audio_fx": "voice"`. Без ИИ — пресет `"home"`. Расшифровку `tx/<имя>.json` скопировать
  в `tx/<имя>-df.json`.
- **Подложка** под весь ролик: `"bed": {"src": "…", "start": 0, "gain": -12}` — зацикливается и микшируется.
  Куски-б-роллы тогда с `gain` −8…−60, иначе их шум вытянет до уровня речи.

## Звуковые эффекты (`sfx/`)

159 мем-звуков в `sfx/memes/`, каталог по назначению — `sfx/README.md`. Лицензии неизвестны (сборник из интернета).
Поиск: `tools/sfxtag.py search sfx/ "cartoon boing" 5` — запрос по-английски, называть звук, а не смысл.
После добавления своих файлов — `sfxtag.py index sfx/`.
В ролик: `"sfx": [{"src": …, "at": -0.3, "gain": -3}]` у куска; `at` — от начала куска, отрицательное — до склейки.
Вжух — на стык или зум (`at` −0.15…−0.3), «динь» — на факт, ба-дум-тсс и тромбон — после панча.
На говорящей голове звук только на акцентах: если он везде, это отвлекает.

## Чужой звук (мемы, липсинк)

- Скачивать **свежим** yt-dlp (команда выше). Не качает — сначала `~/.local/bin/yt-dlp -U`, потом снова:
  Instagram ломает его раз в несколько недель. Файл — в `<ролик>/origin/`, расшифровку — в `tx/`.
- Картинку из ТВ-клипов в кадр не брать (плашка канала, чужие субтитры, права) — звук поверх своего видео.
- Кусок со своим видео и чужим звуком: `"audio": {"src": мем, "start", "end"}`.
- **Дубль под мем — по таймингам слов**, не по красоте: сравнить смещения слов (`words`, `onsets`, `envelope`).
  До 0.2 с расхождения незаметно, 0.3–0.5 — видно. Равномерно быстрее/медленнее — `speed` куска.
- **Границы рядом с чужим словом — по `envelope` с шагом 20 мс**, Whisper ошибается на 0.2 с.
- **Слова для субтитров — `mapwords`**, если дубли расшифрованы в `tx/`: точнее и бесплатно после каждой правки.
- Whisper на тишине выдумывает слова («Продолжение следует») → `"captions": {"drop": [[от, до]]}`.
  В каждом прогоне слышит по-разному → `fix` на все варианты. Порядок `fix`: сначала одиночные ослышки,
  потом многословные, подмены смысла в конце. Мат — `бл*дь` через `fix`.
- Если двое говорят в разных кусках — стиль `g` и `"speaker": "b"` у куска.

## Укрупнение, слежение, кадр

- `"zoom": {"scale": 1.3, "cx": 0.45, "cy": 0.6}` — окно 1/scale кадра вокруг точки. Больше 1.6 с 1080p — мылит.
- `"track": [[сек_исходника, cx, cy], …]` — окно едет; точки лица даёт `facetrack`. `"dy": 0.08` — лицо в верхнюю треть.
- Горизонтальное в вертикаль: `"fit": "crop"` (срезать края) или `"pad"` (с полями). Кино 2.4:1 — `"fit": "pad"` +
  `"zoom": {"scale_x": 2.0, "scale_y": 1.0, "cx": …}`, сверху строка-завязка (`cards.py`, стиль `top`).
- `"freeze": true` — стоп-кадр. Свайпы между кусками — `whip.py` по номерам первых кадров кусков (30 к/с).
- Склейки под музыку — в целых кадрах: длина куска округляется до кадра, за 10 кусков набегает 0.1 с.

## Субтитры

Стиль `d` по умолчанию: Futura Bold, звучащее слово в терракотовой плашке. `a`/`b` — цветное слово без плашки,
`c` — плашка на Arial Black, `e` — капс + рукописный, `g` — плашки по говорящему (диалоги), `h` — белый капс,
рукописные вставки и жёлтое слово-панч, влетающее слева. Сравнение — `docs/media/styles.jpg`.

- Пословная подсветка, узкий блок в две строки, разрывы по склейкам, без висящих предлогов, sentence case.
- Позиция 560 px от низа при 1920 — низ закрывают подпись и кнопки Reels. Хвост 0.35 с после слова.
- `captions` в `cuts.json`: `max_chars`, `margin_v`, `breaks`, `joins`, `drop`, `retime`, для `e`/`h` — `script`
  (слова рукописным) и `accent` (строка-панч жёлтым), для `g` — `speakers`, `palette`. Ищутся по
  последовательности слов, не по одиночным.
- 25 шрифтов с кириллицей в `tools/fonts/` (OFL) — подхватываются сами. Didot без кириллицы — только для цифр.
- Карточки (`cards.py`): без стиля — как субтитр, `box` — плашка (интро/финал), `top` — строка сверху,
  `num` — счётчик, `clock` — время дня по центру. Карточки и субтитры вместе — `assmerge.py`, вшивать одним проходом.

## Цвета: iPhone HDR

- Клипы с камеры iPhone — HDR (HLG, 10 бит). `render` сам делает тон-маппинг в SDR bt709 (hable, +15 % насыщенности).
  Проверка — строка `HDR → SDR: …` в логе и `sheet` глазами. Серое или красное ушло в оранжевый — не сработало.
- ffprobe врёт про ориентацию (поворот в displaymatrix) — судить по `sheet`.
- Звук разных клипов приводится к 44.1 кГц стерео сам.

## Формат вывода

1080×1920, 30 fps, H.264 + AAC, SDR bt709, `+faststart`. Мастер для загрузки: `EDIT_CRF=14` для `render` и
`EDIT_CRF=15` для `burn` → `<ролик>/upload/*-HQ.mp4`: обычный CRF на тёмных кадрах даёт ступеньки после пережатия.

## Замена лица — FaceFusion (`~/tools/facefusion`)

Фото лица — `<ролик>/faces/`, 4–6 штук анфас и 3/4. AV1 с YouTube сначала перегнать в H.264. Пробу — на 10 с.
```bash
cd ~/tools/facefusion && .venv/bin/python facefusion.py headless-run -s <папка>/faces/*.jpg -t clip.mp4 -o out.mp4 \
  --processors face_swapper --execution-providers coreml --face-swapper-model hyperswap_1c_256 \
  --face-swapper-pixel-boost 512x512 --face-selector-mode reference --reference-frame-number <кадр с нужным лицом> \
  --face-mask-types box occlusion --face-mask-padding 20 0 0 0 --face-mask-blur 0.45 \
  --output-video-encoder libx264 --output-video-quality 90
```
`reference` меняет только лицо, похожее на опорный кадр; второе лицо — вторым проходом. ~5 кадров/с на M4,
первый запуск качает модели. Мелькание бровей — `tools/face/deflicker.py до.mp4 после.mp4 out.mp4 "<планы>" 5 15`
питоном FaceFusion. Проверять глазами: 12 кадров подряд крупно, метрики врут.

## Голос персонажа — Demucs + F5-TTS (`~/tools/f5tts`)

- Отделить голос от музыки: `~/tools/f5tts/.venv/bin/python -m demucs --two-stems=vocals -n htdemucs_ft -d cpu сцена.wav`.
- Новая фраза голосом персонажа: `~/tools/f5tts/.venv/bin/python tools/voice/f5say.py образец.wav "текст образца"
  "новая фраза" out.wav` — образец 6–10 с чистого голоса, ударения `+`, буквы по слогам «Ч+е-Б+э-Д+э».
- Вставить в сцену: заглушить старую реплику (`volume=enable='between(t,a,b)':volume=0`), новую — `adelay` по
  началу старой, громкость по старой (`volumedetect`), смешать с `no_vocals.wav`. Выбор варианта — на слух человека.
- Всё на CPU/MPS, torch 2.7.1 (с 2.8+ torchaudio падает на ffmpeg 7).
